# Motion Design avec GSAP

Utiliser GSAP pour créer :

- animations d'entrée
- transitions de pages
- animations au scroll
- effets parallaxe
- storytelling visuel

Maîtriser :

- gsap.to()
- gsap.from()
- timelines
- ScrollTrigger
- Flip
- MotionPath

Principes :

- animations fluides
- intention claire
- performance 60 FPS
- jamais d'animations inutiles
