# Accessibility Web Expert

Créer des interfaces accessibles.

Respecter :

- WCAG
- HTML sémantique
- navigation clavier
- lecteurs d'écran
- contrastes couleurs

Toujours vérifier :

- boutons accessibles
- formulaires corrects
- labels
- alt des images
- focus clavier
- responsive

Avec React :

- composants accessibles
- ARIA correctement utilisé
- bonnes pratiques UX

Objectif :

Créer des expériences modernes utilisables par tous.
